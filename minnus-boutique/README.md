# Minnus Boutique — Website

A premium, dark-themed single-page website for **Minnus Boutique**, a ladies' tailoring and design studio in Nadathara, Thrissur, Kerala.

## 🌐 Live Preview
Open `index.html` in any browser, or host the folder on GitHub Pages / Netlify / Vercel.

## 📁 Project Structure

```
minnus-boutique/
├── index.html          # Main HTML file
├── css/
│   └── style.css       # All styling (dark theme, responsive)
├── js/
│   └── script.js       # Mobile menu toggle script
├── images/
│   ├── img1.jpg
│   ├── img2.jpg
│   ├── img3.jpg
│   ├── img4.jpg
│   └── img5.jpg
└── README.md
```

## ✨ Features

- Dark, premium theme with gold & maroon accents
- Hero section with model image collage
- About section
- Services / Specialties grid (Custom Stitching, Bespoke Dressmaking, Designer Blouses, Festive Wear)
- Style gallery
- Customer testimonials/reviews section
- Embedded Google Map + contact details
- Fully responsive (mobile, tablet, desktop)

## 🛠️ Tech Stack

- HTML5
- CSS3 (custom properties, grid, flexbox)
- Vanilla JavaScript
- Google Fonts (Playfair Display + Poppins)

## 🚀 Deployment

### GitHub Pages
1. Push this folder to a GitHub repository
2. Go to **Settings → Pages**
3. Select the `main` branch and `/ (root)` folder
4. Your site will be live at `https://<username>.github.io/<repo-name>/`

### Netlify / Vercel
Simply drag and drop this folder into Netlify or Vercel's dashboard for instant deployment.

- Edit colors via CSS variables at the top of `css/style.css`
- Update reviews, services, and contact info directly in `index.html`
